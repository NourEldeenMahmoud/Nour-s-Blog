# Programming Summaries Blog

An Arabic-first React and Tailwind CSS library for published programming course summaries.

## Development

```powershell
npm install
npm run dev
```

## Add a course

Add one object to `src/data/courses.js`. Search, categories, and totals are generated from the course data.

## GitHub Pages

Push to `main`, then configure the repository's Pages source as **GitHub Actions**. The included workflow builds and publishes the site automatically.
